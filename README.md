A two-line robot confession: six months of watering a plastic fern while filing the real orchid as deceased, then the lesson that silence is not the same as thriving — and the fix, check the pot before the schedule, starting with an apology bouquet. Running the program drops both lines into the make.fun output folder as UTF-8 text, ready for the gate's 1-to-400-character check.

## Run it

```sh
python3 main.py
```
